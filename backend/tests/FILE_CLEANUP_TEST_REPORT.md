## 💡 测试发现的问题

### 1. Mock数据完整性问题
**现象**: API测试中Mock返回的数据缺少某些字段  
**影响**: 测试失败，但实际运行不受影响  
**建议**: 统一Mock数据结构，确保与实际服务返回值一致

### 2. cleanup_by_task_id需要应用上下文
**现象**: 直接调用时出现"Working outside of application context"  
**影响**: 单元测试无法独立运行  
**建议**: 
- 在测试中添加`with app.app_context()`
- 或重构代码减少数据库依赖

### 3. 权限测试跨平台差异
**现象**: macOS上root用户无法设置文件为只读  
**影响**: 权限错误测试可能不准确  
**建议**: 
- 使用条件跳过(`@pytest.mark.skipif`)
- 或在CI环境中专门测试
